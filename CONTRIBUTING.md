# Contributing

Thanks for helping build Harpoon Reimagined. The project is at an early planning stage; discuss substantial changes to scope or architecture before investing in implementation.

## Working agreements

- Keep simulation logic renderer- and UI-independent.
- Prefer explicit units and coordinate conventions in domain code and documents.
- Add or update an architecture decision record when changing a foundational choice.
- Keep scenario data versioned and validate it at load time.
- Do not commit generated builds, local databases, secrets, or third-party assets without appropriate rights.

## Changes

Use focused pull requests. Describe the player-facing or developer-facing outcome, key design choices, and how the change was checked. Link related issues where applicable. Tests and checks will be added as executable components arrive.
