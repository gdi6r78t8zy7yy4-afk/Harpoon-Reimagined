# Game vision

## Premise

Harpoon Reimagined is a near-future maritime command simulation. The player leads forces across air, surface, and subsurface domains, making decisions with incomplete information and limited time.

## Experience goals

- Make detection, identification, uncertainty, and engagement decisions understandable.
- Let players shift between operational planning and detailed 3D observation.
- Support compact authored scenarios and campaigns where earlier outcomes matter.
- Present a readable command interface even when the 3D scene is visually rich.

## Design pillars

1. **Decisions before spectacle:** visual detail supports tactical understanding.
2. **Information has limits:** sensors provide reports and confidence, not omniscience.
3. **Time is a command tool:** pause and acceleration help players manage workload.
4. **Outcomes carry forward:** campaigns preserve meaningful consequences.

## Initial scope

The first playable slice should focus on one small scenario, a limited set of units, movement, contacts, basic orders, and a clear 3D view. Detailed scope and acceptance criteria will be refined in the milestone plan.
